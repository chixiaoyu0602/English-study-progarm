Windows 10 / 11 x64 免安装版。下载 `MarkNote-1.4.2-Windows-x64.exe` 后双击运行。

- **单词色块不再弹窗**：只包含一个英文单词的色块保留颜色和查词功能；短语、从句仍可打开二级分析。缩写词和连字符词按一个单词处理，已有内部标记保留。
- **逐句阅读**：新增「原文／逐句」切换，逐句模式显示编号、留白和分隔线。点击句子编号，可合并上一句、在文字光标处分句、恢复自动分句。修正随编辑定位、自动保存和备份；编号、分隔线不会进入正文或复制内容。
- **单词本发音**：点击单词旁的小喇叭，调用 Windows 本地英语语音。优先按规范化后的词典音标发音；音标或语音不支持时使用系统读音，并明确提示。支持停止播放，不附带大型语音模型。

发音需要 Windows 中已安装的英语语音。缺少时按应用提示添加语音包；首次安装可能需要联网，日常使用可离线。发音使用合成语音，音质由本地语音决定。

兼容原有文章、标注和单词本，备份格式仍为 4。建议升级前导出备份。程序未购买商业代码签名证书。
